# Lambda runtime dependencies.
#
# Deliberately NOT `-r requirements.txt`: uvicorn and its [standard] extras
# (uvloop, httptools, websockets) are dead weight in a Lambda. Mangum drives
# the ASGI app directly and no server is ever started, so every byte of that
# is cold-start cost paid on each scale-out for nothing.
#
# Keep the shared pins in step with requirements.txt by hand. The duplication
# is the honest cost of two runtimes with genuinely different needs; a shared
# file plus a post-install uninstall would be worse, since it downloads and
# compiles the packages first.
